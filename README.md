# Tell a Whole Story in 32 Characters

One Wi-Fi network name of at most 32 characters: the funniest name that
hints at a whole story. This program writes the chosen entry to
`/output/entry.txt`, deterministically.

Entry: **SheTookTheKidsNotThePassword** (28 characters)

> She took the kids, not the password.

A divorce split, listed — and the twist: the one thing she did *not* take
is the Wi-Fi password, so the password was the contested prize all along.

Run: `node main.ts` (Node 22.18+).
